# docsman

**docsman** adalah kit komponen **MDX** untuk membangun dokumentasi yang menarik dan informatif di atas React/Next.js. Semua komponen sudah terdaftar otomatis di `mdxComponents` (`docman-render.tsx`) — cukup tulis tag komponen di file `.mdx`, **tanpa perlu import**.

Dokumentasi ini dibangun menggunakan components dari `packages/docsman/src/components/` itu sendiri.

## Instalasi

Tambahkan `docsman` ke proyek Anda menggunakan salah satu package manager:

<CodeBlock lang="bash" title="install" variant="header" showLineNumbers={false}>
  <CodeBlock.Code value="pnpm add docsman" />
</CodeBlock>

Alternatif cara cepat, jalankan generator proyek:

  <Component>
    <CodeCommand>docsman</CodeCommand>
  </Component>
  <CodePreview lang="mdx" title="index.mdx">

<AlertSection type="info" title="Requirements">
  docsman membutuhkan React 19 dan Next.js 16+. Semua komponen dirender lewat pipeline render `<DocmanLayoutRender>` di `docsman/render`.
</AlertSection>

## Memulai

Ikuti langkah-langkah berikut untuk memakai docsman:

<StepsSection>
  <Step title="Install">
    Tambahkan package dengan `pnpm add docsman` (atau via `CodeCommand` di
    atas).
  </Step>
  <Step title="Impor render">
    Import `DocmanLayoutRender` dari `docsman/render` di halaman
    `[...docs]/page.tsx`.
  </Step>
  <Step title="Tulis MDX">
    Buat dokumen di folder content dan gunakan komponen `<CodeBlock />
    `, `<TableProps />
    `, `<TerminalView />
    `, dan lainnya.
  </Step>
  <Step title="Render & publish">
    Jalankan dev server, preview halaman, lalu deploy ke Vercel.
  </Step>
</StepsSection>

### Catatan

- `docsman` dipublikasikan **secara manual** (jangan jalankan `npm publish` tanpa diminta).
- `dist/` di-_ignore_; app me-resolusi via workspace symlink.
- Deploy ke Vercel: pastikan `apps/docs` memakai `"commonjs"` (bukan `"type": "module"`) untuk menghindari `ERR_REQUIRE_ESM` di runtime.
