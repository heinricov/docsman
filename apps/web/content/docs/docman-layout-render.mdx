`DocmanLayoutRender` adalah **Server Component** (_RSC_) entry untuk merender dokumentasi MDX. Ia membaca file `.mdx` langsung dari filesystem (via `dir` + `slug`), meng-compile dengan **remark-gfm** dan **rehype-pretty-code**, lalu menampilkan header, konten, **TOC**, dan **pagination** previous/next.

Komponen ini tersedia untuk diimport:

- `import { DocmanLayoutRender } from "docsman/render"`

Kode sumber berada di `packages/docsman/src/render/docman-render.tsx`.

## Cara Pakai

Biasanya dipakai di dalam route _catch-all_ `[...docs]/page.tsx` aplikasi:

<CodeBlock lang="tsx" variant="header" fileName="app/[...docs]/page.tsx">
  ```
  import { DocmanLayoutRender } from "docsman/render"
  export default async function DocsPage({
    params,
    }: {
      params: Promise<{ docs?: string[] }>
      }) {
        const { docs = [] } = await params
        const segments = docs[0] === "docs" ? docs.slice(1) : docs
        return (
          <DocmanLayoutRender
          dir="/docs"
          slug={segments.join("/") || "index"}
          />
          )
          }
  ```
</CodeBlock>

## Alur Render

`DocmanLayoutRender` bekerja sebagai berikut:

1. Jika `dir` dikirim, baca file via `getMdxFile(dir, slug)`. Default `slug` adalah `"index"`.
2. Jika file ditemukan, compile source MDX memakai `compileMDX` dengan:
   - `parseFrontmatter: true`
   - `remarkPlugins: [remarkGfm]`
   - `rehypePlugins: [[rehypePrettyCode, { theme: { light: "github-light", dark: "github-dark" }, keepBackground: false }]]`
3. Tampilkan `<HeaderSection>` memakai `frontmatter.title` dan `frontmatter.description`.
4. Render konten MDX di dalam kolom utama.
5. Render `<Toc />` di kolom kanan dan `<PaginationSection>` di bawah konten.
6. Jika file tidak ditemukan, render halaman **Not Found**.
7. Jika `dir` tidak dikirim, render `children` (atau pesan kosong) sebagai fallback.

## Wrapper Khusus MDX

`docman-render.tsx` juga membungkus beberapa komponen agar tahan terhadap transformasi props oleh compiler MDX:

- **`TableProps`** — menormalkan array/objek/JSON dari props `props` lewat `normalizeMdxTableProps` sebelum diteruskan ke `TablePropsBase`.
- **`SelectItem`** — menormalkan props `options` lewat `normalizeMdxOptions` sebelum diteruskan ke `SelectItemBase`.

## Perilaku

- **Sidebar-TOC** — `<Toc />` selalu dirender di kolom kanan.
- **Pagination** — `<PaginationSection>` bernavigasi di antara halaman dalam **root route** yang sama (mis. `components/*` hanya berpasangan dengan sibling `components/*` lain), memakai label dari frontmatter `title`.
- **Styling** — konten dibungkus `<div>` dengan `text-[15px]/relaxed text-foreground/80`.

## Kode Sumber

Berada di `packages/docsman/src/render/docman-render.tsx` dan diekspor ulang melalui `docsman/render` (`index.ts`). Rekan server-render-nya, `PaginationSection`, berada di `packages/docsman/src/render/pagination.tsx`.
