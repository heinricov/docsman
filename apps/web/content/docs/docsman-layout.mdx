`DocsmanLayout` adalah komponen **layout utama** docsman. Ia menerima konfigurasi umum (logo, menu, sosmed, tem, pencarian), menentukan **varian** (`basic` / `floating`), membangun header & footer secara default (atau menerima override), dan memperlihatkan/menyembunyikan **sidebar** secara otomatis berdasarkan pathname aktif.

Komponen ini adalah **Client Component** (`"use client"`) dan tersedia untuk diimport via:

- `import { DocsmanLayout } from "docsman"`
- `import { DocsmanLayout } from "docsman/layouts"`

Kode sumber berada di `packages/docsman/src/layouts/docsman-layout.tsx`.

## Cara Pakai

Gunakan sebagai pembungkus `<body>` di dalam `RootLayout` aplikasi:

<CodeBlock lang="tsx" variant="header" fileName="app/layout.tsx">
  ```
  import './globals.css'
  import { ThemeProvider } from '@/components/theme-provider'
  import { DocsmanLayout } from 'docsman/layouts'
  
  export default function RootLayout({
    children
    }: Readonly<{ children: React.ReactNode }>) {
      return (
        <html lang="en" suppressHydrationWarning>
          <body>
            <ThemeProvider>
              <DocsmanLayout
              title="Docsman"
              ShowSidebar="/docs"
              sideMenus={menus}
              >
              {children}
              </DocsmanLayout>
              </ThemeProvider>
              </body>
              </html>
              )
              }
  ```
</CodeBlock>

## Varian Layout

`DocsmanLayout` mendelegasikan render ke salah satu dari dua layout:

  />
  <PropItem
    props="floating"
    type="LayoutFloating"

  />

Contoh memilih varian `floating`:

<CodeBlock lang="tsx" variant="header" fileName="app/layout.tsx">
  ```
  <DocsmanLayout variant="floating" title="Docsman" sideMenus={menus}>
    {children}
  </DocsmanLayout>
  ```
</CodeBlock>

## Perilaku

- **Sidebar otomatis** — sidebar disembunyikan di layar desktop ketika pathname saat ini tidak cocok dengan `ShowSidebar` (prefix). Cocok jika `pathname === path` atau dimulai dengan `path/`. Jika `ShowSidebar` tidak dikirim, sidebar selalu tampil.
- **Header & footer default** — `Header` dan `Footer` di-build otomatis dari `AppHeader`/`AppFooter` memakai `logo`, `theme`, `search`, dan `sosmeds`. Menu header/footer diseleksi dari `sideMenus` (section ber-`type: "Header"` / `"Footer"` dan tidak `hidden`).
- **Override** — kirim `Header` / `Footer` (ReactNode) untuk mengganti render sepenuhnya, atau `HeaderMenus` / `FooterMenus` untuk mengganti hanya daftar menunya.
