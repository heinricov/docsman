# CardSection

`CardSection` adalah kumpulan komponen untuk menampilkan **kumpulan kartu** dalam **grid responsif** di dokumentasi MDX. Cocok untuk showcase fitur, daftar item, atau galeri.

Dua komponen penyusunnya terdaftar otomatis di `mdxComponents` (`docman-render.tsx`), jadi **tidak perlu import** apa pun di file MDX:

- `CardSection` → wadah grid responsif; props: `children`, `className`, `columns`.
- `Card` → kartu dengan `title` + `description`; props: `title`, `description`, `className`.

## Perilaku & Catatan

- **Grid responsif** — `CardSection` memakai `grid grid-cols-1` di mobile dan `sm:grid-cols-N` sesuai `columns` (2/3/4) di layar lebih lebar.
- **Rata tengah** — item grid diatur `place-items-center` agar selalu rapi.
- **Berbasis `Card` shadcn** — `Card` menyusun `CardPrimitive`, `CardHeader` (judul), dan `CardContent` (deskripsi).
- **Tidak memakai hook** — `CardSection` dan `Card` adalah komponen server-safe (tanpa `"use client"`), bisa dirender langsung di Server Component / MDX.
- `columns` hanya berpengaruh pada viewport `sm` ke atas; di mobile selalu satu kolom.
- Karena disusun dalam `<Component>` preview, gunakan `flexCol` agar kartu tersusun vertikal di area demo.
