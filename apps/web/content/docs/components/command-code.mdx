# CodeCommand

`CodeCommand` adalah komponen yang menampilkan perintah terminal dengan tab untuk empat **package manager** sekaligus: pnpm, npm, yarn, dan bun. Komponen ini otomatis dilengkapi **syntax highlighting**, indikator prompt `$`, serta tombol **copy ke clipboard**.

Komponen ini bersifat **client component** (`"use client"`) dan sudah terdaftar otomatis di `mdxComponents` pada `docman-render.tsx`, sehingga **tidak perlu import tambahan** di file MDX — langsung pakai tag `<CodeCommand>`.

## Mode Eksekusi (`execute`)

Setel `execute` untuk menampilkan perintah jalankan langsung, bukan instalasi:

<CodeCommand execute defaultTab="npm">
  shadcn@latest init --preset b1tMcUdYu --template next --pointer
</CodeCommand>

<ComponentCodePreview>
  <Component>
    <CodeCommand execute>create-docsman-app</CodeCommand>
  </Component>
  <CodePreview lang="tsx" title="command-code.mdx">
    ```
    <CodeCommand execute>create-docsman-app</CodeCommand>
    ```
  </CodePreview>
</ComponentCodePreview>

Perintah yang dihasilkan mengikuti kebiasaan tiap package manager:

- `pnpm dlx create-docsman-app`
- `npx create-docsman-app`
- `yarn dlx create-docsman-app`
- `bunx --bun create-docsman-app`

## Perilaku & Detail

- **Instalasi vs Eksekusi** — verb per package manager:
  - instalasi (`execute={false}`): `pnpm add`, `npm install`, `yarn add`, `bun add`
  - eksekusi (`execute={true}`): `pnpm dlx`, `npx`, `yarn dlx`, `bunx --bun`
- **Auto tema** — mengikuti mode `dark`/`light` aplikasi secara real-time (via `MutationObserver` pada kelas `dark` di `documentElement`).
- **Copy** — tombol copy di kanan memakai `useCopyToClipboard`; ikon berubah jadi `Check` berwarna hijau saat berhasil.
- **Hydration-safe** — `CommandRow` hanya me-render `SyntaxHighlighter` setelah komponen ter-mount di browser untuk mencegah hydration mismatch (SSR flicker), dengan fallback `<pre>` polos.

## Kode Sumber

Komponen berada di `packages/docsman/src/components/code-command.tsx` dan diekspor ulang melalui `docsman/render-client` untuk dipakai di pipeline render MDX (`docman-render.tsx`).
