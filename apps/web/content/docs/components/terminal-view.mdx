# TerminalView

`TerminalView` adalah kumpulan komponen untuk menampilkan **simulasi terminal interaktif** dalam dokumentasi MDX. Ia punya jendela bergaya macOS (titik merah/kuning/hijau), baris perintah, dan urutan **step** yang bisa dinavigasi otomatis (`process`) atau ditampilkan sekaligus.

Komponen-komponen berikut terdaftar otomatis di `mdxComponents` (`docman-render.tsx`), jadi **tidak perlu import** di file MDX:

- `TerminalView` → jendela terminal utama.
- `Command` → baris perintah (`$`).
- `Process` → proses berjalan (spinner) lalu selesai (check).
- `Question` → pertanyaan menunggu jawaban.
- `SelectItem` → pertanyaan dengan daftar pilihan (`<Option>`).
- `Resault` + `ResaultItem` → hasil/tampilan output.
- `Massage` → pesan info dengan ikon.

## Tampilkan Semua Step (`process={false}`)

Tanpa `process`, semua step ditampilkan sekaligus dalam satu jendela:

  <Component flexCol>

      <Command command="pnpm add docsman" />
      <Process command="Resolving packages..." done />
      <Massage description="Setup Success !" />
    </TerminalView>

## Mode Proses (`process`)

Set `process` agar step tampil **berurutan** seperti proses nyata:

<CodeBlock lang="mdx" title="terminal-view.mdx">
  <CodeBlock.Code value={"<TerminalView title=\"deploy\" process>\n  <Command command=\"git push origin main\" />\n  <Process command=\"Uploading artifacts...\" interactive={1} />\n  <Question command=\"Aktifkan production? \" done />\n  <Resault command=\"Build selesai\">\n    <ResaultItem>Deployed to Vercel</ResaultItem>\n  </Resault>\n</TerminalView>"} />
</CodeBlock>

  <Component flexCol>
    <TerminalView title="deploy" process>

      <Process command="Uploading artifacts..." />
      <Question command="Aktifkan production? " />

  </Component>

## Pilihan dengan `SelectItem` + `Option`

`SelectItem` menampilkan pertanyaan dengan daftar pilihan. Gunakan `<Option value="..." />` sebagai children (paling stabil di MDX):

<ComponentCodePreview>
  <Component flexCol>
    <TerminalView title="setup">
      <Question command="Pilih framework?" answer="Next.js" done />
      <SelectItem command="Pilih package manager" select="pnpm">
        <Option value="pnpm" />
        <Option value="npm" />
        <Option value="yarn" />
      </SelectItem>
      <Massage description="Setup selesai" />
    </TerminalView>
  </Component>

## Perilaku & Catatan

- **`process`** — tanpa nilai, semua step tampil sekaligus. Dengan `process`, step muncul satu-per-satu; `interactive` (dalam detik) mengendalikan jeda sebelum lanjut. Tombol reload di kanan atas mereset urutan.
- **`Option`** — hanya *carrier data* (render `null`); gunakan sebagai children `<SelectItem>`. Format via children lebih stabil di MDX daripada array literal `options={[...]}`.
- **Auto-navigasi** — saat `process`, `Command`/`Process`/`Question`/`SelectItem` otomatis maju ke step berikut lewat hook `useStepTimer`.
- **Ikon & status** — `Command` memakai `$` (biru), `Process` spinner kuning → check hijau, `Question` tanda `?` kuning → check hijau + jawaban.
- **Anti-duplikasi** — `TerminalView` mem-flatten children dengan strategi exclusive (unwrap wrapper DOM/typography, skip `Option` di daftar step) untuk menghindari duplikasi key React.
- **`SelectItem`** — dalam render terminal memakai wrapper server-friendly yang menormalisasi `options` sebelum diteruskan ke komponen asli; punya `data-selftest="OK"` dan atribut debug (`data-options-source`, `data-options-count`, dll.) di DOM.
- Jendela memiliki scroll area (`max-h-64`) dan footer navigasi (`Navigate` + tombol arah + `Enter`).
- Semua step komponen adalah **client component** (`"use client"`), jadi interaksi berjalan di browser.
