# FileTree

`FileTree` adalah kumpulan komponen untuk menampilkan **struktur direktori** dalam dokumentasi MDX. Folder dirender sebagai node yang **bisa dibuka/ditutup** (collapsible), dan file sebagai node daun dengan ikon. Berguna untuk mendokumentasikan struktur proyek.

Tiga komponen penyusunnya terdaftar otomatis di `mdxComponents` (`docman-render.tsx`), jadi **tidak perlu import** apa pun di file MDX:

- `FileTree` → wadah luar struktur.
- `Folder` → folder (collapsible): `title`, `open`, `children`.
- `File` → file (node daun): `title`.

## Perilaku & Catatan

- **Collapsible** — `Folder` memakai `Collapsible` (base-ui). Klik pada baris folder untuk membuka/menutup; ikon berganti antara `FaFolder` (tertutup) dan `FaFolderOpen` (terbuka).
- **Ikon file** — `File` memakai `FileIcon` dari `lucide-react`.
- **Indentasi** — konten diindentasi dengan `border-l` agar hierarki terbaca.
- **State interaktif** — karena `"use client"`, folder bisa di-toggle oleh pengguna; `open` hanya menentukan state awal.
- **Flex layout demo** — pada contoh di atas, demo `FileTree` dibungkus `<Component flexCol>` agar struktur vertikal terlihat jelas; `FileTree` sendiri berukuran `w-full`.
- `FileTree` tidak menerima prop khusus selain `children`.
