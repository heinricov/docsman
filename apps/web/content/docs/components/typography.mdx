# Typography

`Typography` adalah himpunan komponen tipografi dasar untuk dokumentasi MDX: heading (`H1`–`H6`), paragraf, blockquote, daftar, kode, prateks, tautan, garis pemisah, tebal, dan miring.

Komponen ini terdaftar di `mdxComponents` (`docman-render.tsx`) dan dipakai sebagai **renderer default** untuk elemen Markdown/MDX standar. Jadi `> catatan`, `**tebal**`, `# Judul`, dan seterusnya otomatis memakai gaya ini — **tanpa perlu import**. Nama komponen (`H1`, `P`, `Code`, dll.) juga bisa dipakai langsung sebagai tag di MDX bila ingin lebih eksplisit.

## Komponen

Semua komponen menerima `children` (ReactNode), `className` opsional (ditambahkan lewat `cn`), dan sebagian juga `id`.

## Heading

Heading memakai `scroll-m-20` untuk anchor scroll yang rapi dan mendukung prop `id`:

</CodeBlock>

## Markdown Standar (default renderer)

Karena komponen ini adalah renderer default, Markdown biasa otomatis ter-*style*:

## Perilaku & Catatan

- **Renderer default** — `H1`–`H6`, `P`, `Blockquote`, `Ul`, `Ol`, `Li`, `Code`, `Pre`, `A`, `Hr`, `Strong`, `Em` dipetakan ke tag Markdown standar di `mdxComponents`, jadi seluruh konten MDX otomatis memakai gaya ini.
- **`className` bisa ditimpa** — setiap komponen menggabungkan class default dengan `className` via `cn`, sehingga bisa di-override.
- **`id` untuk anchor** — heading mendukung `id` dan `scroll-m-20`; cocok untuk anchor/link langsung ke bagian.
- **Server-safe** — komponen tanpa `"use client"` (murni stateless), bisa dirender langsung di Server Component / MDX.
- **`Hr` khusus** — hanya menerima `className`; tidak punya `children`/`id`.
- **`typographyComponents`** — file juga mengekspor `typographyComponents` (peta `h1`→`H1`, dst.) untuk kebutuhan mapping MDX manual.
