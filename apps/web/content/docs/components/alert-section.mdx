# AlertSection

`AlertSection` adalah komponen **alert / pemberitahuan** dalam dokumentasi MDX, dibangun di atas `Alert` (shadcn) dengan dukungan beberapa **varian** (`default`, `success`, `warning`, `info`, `error`). Setiap varian punya ikon dan warna yang berbeda.

Komponen ini terdaftar otomatis di `mdxComponents` (`docman-render.tsx`), jadi **tidak perlu import** apa pun di file MDX — langsung pakai tag `<AlertSection>`.

## Perilaku & Catatan

- **Berbasis `Alert` shadcn** — nyusun `AlertTitle` dan `AlertDescription`; komponen ini memakai `../ui/alert`.
- **Ikon & warna per varian** — `alertConfig` memetakan tiap `type` ke ikon `lucide-react` dan class warna yang sesuai.
- **`title` wajib** — `title: string` (wajib); `type` opsional (default `default`).
- **`children` bebas** — bisa berupa teks, markdown, atau komponen lain sebagai deskripsi.
- Karena `AlertSection` **tidak** memakai hook (komponen server-safe, tanpa `"use client"`), ia bisa dirender langsung di Server Component / MDX.

## Kode Sumber

Berada di `packages/docsman/src/components/alert-section.tsx` dan diekspor ulang melalui `docsman/render-client` untuk dipakai di pipeline render MDX (`docman-render.tsx`). Ekspor: `AlertSection`.
