# LogoSection

`LogoSection` adalah kumpulan komponen untuk menampilkan **barisan logo/teknologi** dalam **grid responsif** di dokumentasi MDX — misalnya daftar teknologi/stack yang dipakai sebuah proyek. Setiap logo dirender sebagai kartu kecil (ikon + nama, tampil grayscale dengan efek warna saat hover).

Dua komponen penyusunnya terdaftar otomatis di `mdxComponents` (`docman-render.tsx`), jadi **tidak perlu import** apa pun di file MDX:

- `LogoSection` → wadah grid responsif; props: `children`, `className`, `columns`.
- `Logo` → satu logo; props: `icon` (key string), `title`.

## Mengenal Key Ikon

`Logo` menerima nama ikon sebagai **string key** (bukan komponen). Jika key tidak dikenali, hanya `title` yang dirender (tanpa ikon).

## Perilaku & Catatan

- **Key string ikon** — `icon` adalah nama string yang dipetakan lewat `iconMap`; tidak menerima komponen langsung. Fallback menampilkan `title` saja bila key tidak dikenal.
- **Efek hover** — kartu logo dirender `grayscale` dan menjadi berwarna saat hover (`hover:grayscale-0`), mengikuti aturan "logo stack".
- **Ikon bisa di-import** — file juga mengekspor ulang ikon (`Si*`, `Ri*`) dari `react-icons`, agar bisa dipakai langsung sebagai komponen di MDX bila diperlukan.
- **Grid responsif** — `grid-cols-2` di mobile, `sm:grid-cols-3`, lalu `sm:grid-cols-N` (2–6) sesuai `columns`; `place-items-center` menjaga kerapian.
- **Server-safe** — `LogoSection` dan `Logo` tanpa `"use client"` (tidak memakai hook), bisa dirender langsung di Server Component / MDX.
