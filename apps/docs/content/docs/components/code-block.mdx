# CodeBlock

`CodeBlock` adalah komponen serbaguna untuk menampilkan **blok kode** dalam dokumentasi MDX: syntax highlighting (Prism), ikon bahasa, nomor baris, highlight/fokus baris tertentu, mode **tabs**, mode **diff**, auto-format (Prettier), dan tombol copy.

Komponen sudah terdaftar di `mdxComponents` (`docman-render.tsx`), termasuk sub-komponennya:

- `CodeBlock` → `<CodeBlock>`
- `CodeBlock.Code` → `<CodeBlock.Code />`
- `CodeBlock.Line` → `<CodeBlock.Line />`
- `CodeBlock.Tab` → `<CodeBlock.Tab />`

Jadi **tidak perlu import** apa pun di file MDX.

## Penggunaan Dasar

### a. Dengan `CodeBlock.Code`

```mdx
<CodeBlock lang="typescript" title="types.ts">
  <CodeBlock.Code value="interface User {\n  name: string\n  age: number\n}" />
</CodeBlock>
```

<CodeBlock lang="typescript" title="types.ts">
  <CodeBlock.Code value="interface User {\n  name: string\n  age: number\n}" />
</CodeBlock>

### b. Dengan beberapa `CodeBlock.Line`

```mdx
<CodeBlock lang="bash" title="install.sh">
  <CodeBlock.Line value="pnpm install docsman" />
  <CodeBlock.Line value="pnpm add react-syntax-highlighter" />
</CodeBlock>
```

<CodeBlock lang="bash" title="install.sh">
  <CodeBlock.Line value="pnpm install docsman" />
  <CodeBlock.Line value="pnpm add react-syntax-highlighter" />

### c. Lewat prop `code`

```mdx
<CodeBlock lang="tsx" code="const x = 1" />
```

## Variant `header` — Tampilkan Nama File

```mdx
<CodeBlock lang="ts" variant="header" fileName="app.ts" showLineNumbers={false}>
  <CodeBlock.Code value="const app = createApp()" />
</CodeBlock>
```

<CodeBlock lang="ts" variant="header" fileName="app.ts" showLineNumbers={false}>
  <CodeBlock.Code value="const app = createApp()" />

## Variant `tabs` — Perintah Multi-Package-Manager

Gunakan `<CodeBlock.Tab value="label" lang="bash">kode</CodeBlock.Tab>` di dalam children:

```mdx
<CodeBlock variant="tabs" defaultTab="pnpm">
  <CodeBlock.Tab value="pnpm" lang="bash">pnpm add docsman</CodeBlock.Tab>
  <CodeBlock.Tab value="npm" lang="bash">npm install docsman</CodeBlock.Tab>
  <CodeBlock.Tab value="yarn" lang="bash">yarn add docsman</CodeBlock.Tab>
</CodeBlock>
```

<CodeBlock variant="tabs" defaultTab="pnpm">

  <CodeBlock.Tab value="npm" lang="bash">npm install docsman</CodeBlock.Tab>
  <CodeBlock.Tab value="yarn" lang="bash">yarn add docsman</CodeBlock.Tab>

Anda juga bisa definisikan hanya label tab via prop `tabs`:

```mdx
<CodeBlock variant="tabs" tabs="npm,pnpm,yarn" defaultTab="npm">
  <CodeBlock.Tab value="npm" lang="bash">npm init docsman</CodeBlock.Tab>
  <CodeBlock.Tab value="pnpm" lang="bash">pnpm create docsman</CodeBlock.Tab>
  <CodeBlock.Tab value="yarn" lang="bash">yarn create docsman</CodeBlock.Tab>
</CodeBlock>
```

## Highlight & Focus Baris

- `highlight` → warnai baris tertentu.
- `focus` → redupkan semua baris kecuali yang difokuskan.

```mdx
<CodeBlock lang="bash" highlight="[1,3]" focus="[1]">
  <CodeBlock.Line value="pnpm install" />
  <CodeBlock.Line value="pnpm add docsman" />
  <CodeBlock.Line value="pnpm run build" />
</CodeBlock>
```

  <CodeBlock.Line value="pnpm add docsman" />
  <CodeBlock.Line value="pnpm run build" />
</CodeBlock>

## Mode Diff

Tampilkan perubahan kode (hijau = tambahan, merah = penghapusan):

```mdx
<CodeBlock title="ubah konstanta" oldCode="const a = 1" newCode="const a = 2" />
```

<CodeBlock title="ubah konstanta" oldCode="const a = 1" newCode="const a = 2" />

Untuk multi-line, gunakan `\n` dalam string:

```mdx
<CodeBlock
  oldCode="const a = 1\nconst b = a + 1"
  newCode="const a = 2\nconst b = a + 1\nconsole.log(b)"
/>
```

<CodeBlock
  oldCode="const a = 1\nconst b = a + 1"
  newCode="const a = 2\nconst b = a + 1\nconsole.log(b)"
/>

## Perilaku & Catatan

- **Auto tema** — ikut mode `dark`/`light` aplikasi secara real-time (via `MutationObserver` pada kelas `dark`).
- **Auto format** — `autoFormat={true}` menjalankan Prettier via `formatCode` sesuai bahasa; matikan jika kode sudah diformat manual.
- **Copy** — tombol muncul saat hover di pojok kanan atas (`useCopyToClipboard`).
- **Extraction dari children** — `CodeBlock.Code`/`.Line`/`.Tab` membawa data lewat children/props string sehingga kompatibel dengan compiler MDX yang kadang membuang prop objek/array (pendekatan `extractTextContent` / `flattenElementChildren`).
- Untuk banyak kasus, **auto-format** (Prettier) sudah menormalkan isi kode, sehingga tidak perlu menulis ulang indentasi manual.
