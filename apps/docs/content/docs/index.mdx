**docsman** adalah kit komponen **MDX** untuk membangun dokumentasi yang menarik dan informatif di atas React/Next.js. Semua komponen sudah terdaftar otomatis di `mdxComponents` (`docman-render.tsx`) — cukup tulis tag komponen di file `.mdx`, **tanpa perlu import**.

Dokumentasi ini dibangun menggunakan components dari `packages/docsman/src/components/` itu sendiri.
