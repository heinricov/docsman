### Create a Next.js Project

Buat project Next.js baru menggunakan shadcn/create. Anda dapat mengikuti dokumentasi resmi shadcn untuk proses pembuatan project di [shadcn/ui create](https://ui.shadcn.com/create), atau menggunakan perintah berikut:

<CodeCommand execute defaultTab="npm">
  shadcn@latest init --preset b1tMcUdYu --template next --pointer
</CodeCommand>

Perintah tersebut akan membuat project Next.js yang sudah dikonfigurasi dengan shadcn sebagai dasar project.

masuk ke project yang anda buat:
`cd my-docs`
Ganti my-docs dengan nama project yang Anda gunakan.

### Install Docsman

Install package Docsman

<CodeCommand defaultTab="npm">docsman</CodeCommand>

Setelah proses instalasi selesai, Docsman dapat digunakan di dalam project Next.js Anda.

### Update app/layout.tsx

app/layout.tsx

Kemudian import dan gunakan `DocsmanLayout` dari `Docsman` sebagai layout utama aplikasi.

<CodeBlock lang="tsx" variant="header" fileName="layout.tsx" >

    ```
    import "./globals.css"
    import { ThemeProvider } from "@/components/theme-provider"
    import { cn } from "@/lib/utils"

    import { DocsmanLayout } from "docsman/layouts"

    export default function RootLayout({
    children,
    }: Readonly<{
    children: React.ReactNode
    }>) {
    return (
        <html
        lang="en"
        suppressHydrationWarning
        >
        <body>
            <ThemeProvider>
            <DocsmanLayout>{children}</DocsmanLayout>
            </ThemeProvider>
        </body>
        </html>
    )
    }
    ```

</CodeBlock>

DocsLayout bertanggung jawab menyediakan struktur dasar dan layout yang diperlukan oleh website dokumentasi.

### Update app/globals.css

Tambahkan konfigurasi CSS yang diperlukan oleh Docsman sesuai dengan template atau konfigurasi CSS yang tersedia pada dokumentasi Docsman.

<CodeBlock lang="css" variant="header" fileName="app/globals.css" >

    ```
    @import "tailwindcss";
    @import "tw-animate-css";
    @import "shadcn/tailwind.css";
    @import "docsman/globals.css";

    @custom-variant dark (&:is(.dark *));
    @source "../app/**/*.{ts,tsx}";
    @source "../../../node_modules/docsman";
    ```

</CodeBlock>

### Create the Documentation Route

File page.tsx akan menjadi dynamic catch-all route yang digunakan Docsman untuk menangani halaman dokumentasi.

### Configure DocmanLayoutRender

Kemudian import `DocmanLayoutRender` dari package Docsman dan gunakan sebagai renderer untuk konten dokumentasi.

<CodeBlock lang="tsx" variant="header" fileName="[...docs]/page.tsx" >

    ```tsx
    import { DocmanLayoutRender } from "docsman/render"

    export default async function DocsPage({
    params,
    }: {
    params: Promise<{ docs?: string[] }>
    }) {
    const { docs = [] } = await params
    const segments = docs[0] === "docs" ? docs.slice(1) : docs

    return <DocmanLayoutRender dir="/docs" slug={segments.join("/") || "index"} />
    }
    ```

</CodeBlock>
